# expense_tracker
A simple and interactive Expense Tracker web application built using HTML, CSS, and JavaScript. It allows users to manage their personal finances by tracking income and expenses.

---

## ✨ Features

- ✅ Add income or expense transactions
- ✅ Auto-update balance, income, and expense summary
- ✅ Display a dynamic list of all transactions
- ✅ Delete individual transactions
- ✅ Data persistence using `localStorage`
